Quickstart

Your first comparison
in three steps.

PromptTrace works with any provider that implements the OpenAI-compatible Chat Completions API. Credentials remain on your server.

{{ 'This instance is configured' if provider_ready else 'This instance still needs a provider' }}
01

Configure once

Connect your endpoint

Set the full Chat Completions URL, API key, and default model before starting PromptTrace.

Environment
export PROMPTTRACE_API_URL="https://api.example.com/v1/chat/completions"
export PROMPTTRACE_API_KEY="your-api-key"
export PROMPTTRACE_MODEL="your-model"

For a local server without authentication, omit PROMPTTRACE_API_KEY.

02

Build the test

Add prompt variants

Open the workbench, keep the shared system prompt constant, and give each column a prompt, model, and temperature. Add as many columns as the experiment needs.

Learn from it
